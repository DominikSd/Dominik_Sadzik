# Strona — Dominik Sadzik

Szkielet projektu React + Vite + Tailwind stworzony na podstawie przesłanego komponentu.

Uruchomienie lokalne:

1. Otwórz terminal w folderze `Dominik_Sadzik`
2. Zainstaluj zależności:

```bash
npm install
```

3. Uruchom serwer deweloperski:

```bash
npm run dev
```

Otwórz podany adres (domyślnie http://localhost:5173).

Kluczowe pliki:
- [index.html](index.html)
- [src/LandingPage.jsx](src/LandingPage.jsx)
- [src/main.jsx](src/main.jsx)
- [src/index.css](src/index.css)

Chcesz, żebym teraz uruchomił `npm install` i sprawdził działanie serwera? Jeśli tak, potwierdź, to wykonam.
