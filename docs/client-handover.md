# Client Handover

## What The Panel Can Do

- Edit hero text.
- Edit offer/services.
- Edit FAQ.
- Edit contact data.
- Edit SEO title and description.
- Save drafts.
- Publish approved changes.
- View basic GA4 statistics.

## What The Panel Does Not Do Yet

- It is not a drag-and-drop website builder.
- It does not upload media.
- It does not manage files in Supabase Storage.
- It does not include AI Assistant yet.
- It does not store raw analytics events in Supabase.

## Daily Workflow

1. Open the private admin hash route.
2. Log in.
3. Pick a section.
4. Edit normal form fields.
5. Save draft.
6. Publish when ready.
7. Check `Statystyki` for traffic and event trends.

## Safety Notes

- Users with `viewer` role can inspect but cannot save or publish.
- Keep passwords private.
- Do not share the private panel link publicly.
- GA4 reports depend on Google Analytics and Supabase Edge Function configuration.
